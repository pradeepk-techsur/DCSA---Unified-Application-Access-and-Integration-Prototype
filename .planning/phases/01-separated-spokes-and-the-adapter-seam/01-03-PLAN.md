<objective>
Build the adapter seam — the phase's primary architectural deliverable. Three parts, all three of
which must hold: a compiler-checked interface every adapter implements identically, a shared runtime
that applies deadline/retry/backoff/circuit/normalization-validation/error-classification *outside*
every adapter, and the Ed25519 audience-bound principal assertion that makes a spoke able to trust
the hub without authenticating a user itself.

Purpose: everything else in this prototype could be rebuilt in a different framework; the claim that
survives is *"onboarding the sixth application is a configuration change, not a code change,"* and
this seam is the only thing that makes it true.
Output: `@ual/adapter-contract`, `@ual/assertions`, `@ual/adapter-runtime`, `@ual/adapter-rest-json-v1`.
</objective>

**`src/invoke.ts`** — transcribe the algorithm from §5.2:
1. Circuit gate — `healthCheck` is **exempt in every state**, so recovery stays detectable
   (`FR-F08a-05` rule 5). Non-exempt call with an open circuit → throw `ADAPTER_CIRCUIT_OPEN`,
   `retryable: false`.
2. `maxAttempts = mutating ? 1 : cfg.maxRetries + 1` — **`performAction` is never auto-retried.**
3. Per-attempt budget check against `ctx.deadlineAt`; a non-positive budget throws `ADAPTER_TIMEOUT`.
4. On success: `validateAgainstSchema(operation, result, applicationId)` (a malformed adapter
   response is `ADAPTER_CONTRACT_ERROR`, never a silently-accepted shape), `circuit.recordSuccess`,
   structured log, return.
5. On failure: `classify(err, ...)`; **if mutating and the class is `ADAPTER_TIMEOUT`, rewrite it to
   `ADAPTER_INDETERMINATE` with `retryable: false`** — auto-retry there would risk double-applying;
   `circuit.recordFailure`; `issues.record(...)` unless the class is `ADAPTER_NOT_FOUND` or
   `ADAPTER_REJECTED` (`FR-F08a-06` rule 1 — those are business outcomes, not integration failures);
   retry only if `retryable && attempt < maxAttempts` AND the backoff delay fits inside the deadline.
   **Never retry past the deadline.**

**`src/circuit.ts`** — the ~140-line hand-written state machine (ADR-007 explains why not `opossum`).
One instance per `applicationId`. Transitions per the §5.2 diagram:
`CLOSED --consecutiveFailures >= circuitFailureThreshold--> OPEN --after circuitOpenMs--> HALF_OPEN`;
`HALF_OPEN` admits `circuitHalfOpenProbes` calls; success → `CLOSED`; failure → `OPEN` with the timer
reset. `healthCheck()` **bypasses this machine entirely in every state.** Every transition emits an
`integration_issues` record through the `IssueSink` and is designed to persist to
`hub.application_health` — expose a `CircuitStateStore` port for that persistence and ship an
in-memory implementation here; plan 01-06 wires the pg-backed one. Defaults come from the registry
row (threshold 5, open 30 000 ms, half-open probes 1), never from constants in this file.

**`src/backoff.ts`** — `backoffInitialMs × multiplier^(attempt-1)`, ± `jitterPct`, per `FR-F08a-05`
rule 2. Make the jitter source injectable so tests are deterministic.

**`src/classify.ts`** — map a caught error to one of the thirteen classes:

| Cause | Class | Retryable |
|---|---|---|
| `ECONNREFUSED` / DNS / TLS failure | `ADAPTER_UNREACHABLE` | yes |
| `AbortError` / deadline exceeded | `ADAPTER_TIMEOUT` | non-mutating only |
| spoke 401 `PRINCIPAL_REJECTED` | `ADAPTER_PRINCIPAL_REJECTED` | no |
| spoke 403 `FORBIDDEN` | `ADAPTER_FORBIDDEN` | no |
| spoke 404 `NOT_FOUND` | `ADAPTER_NOT_FOUND` | no |
| spoke 409 / 422 | `ADAPTER_REJECTED` | no |
| spoke 429 | `ADAPTER_RATE_LIMITED` | yes, with `retryAfter` |
| spoke 502/503/504 | `ADAPTER_UNREACHABLE` | yes |
| response failed schema validation | `ADAPTER_CONTRACT_ERROR` | no |
| out-of-scope rows returned | `ADAPTER_SCOPE_VIOLATION` | no |
| unsupported `contractVersion` | `ADAPTER_CONTRACT_UNSUPPORTED` | no |
| anything else | `ADAPTER_INTERNAL` | no |

`ADAPTER_CIRCUIT_OPEN` and `ADAPTER_INDETERMINATE` are produced by `invoke()` itself, not by
`classify()`. **Never retry a 4xx, `ADAPTER_REJECTED`, `PRINCIPAL_REJECTED`, or
`ADAPTER_CONTRACT_ERROR`** (`FR-F08a-05` rule 3) — retrying those is guaranteed waste.
